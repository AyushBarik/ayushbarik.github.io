  • GPT-2 in CUDA Report (PDF)
    Ayush Barik, Anand Parab, Krishnan Shankar, Sidd Cheetancheri · ECE 408 class project

    We re-implemented GPT-2 inference in CUDA and optimized it for NVIDIA A40 GPUs, using Nsight Systems and Nsight Compute to find bottlenecks. We added FlashAttention-2, sliding-window attention, KV caching, and CUTLASS kernel fusion. Inside the matmul and attention kernels, we hid memory latency with double-buffering and avoided bank conflicts by swizzling shared memory.

  • Real-Time QVGA Video Streaming with Filters on FPGA Report (PDF)
    Ayush Barik, Joanna Li · ECE 385 class project

    We built a real-time video pipeline on a Spartan-7 FPGA that captures a live OV7670 camera feed and renders it to an HDMI monitor. Our SCCB controller configures the camera to output a quantized 12-bit RGB444 QVGA stream, small enough to hold a full frame in on-chip BRAM, and a dual-port frame buffer bridges the camera and display clock domains. On the display side, we generate 640×480 video timing, upscale each frame, and composite color filters, text, and a sprite pixel by pixel, all in 813 LUTs at 0.35 W.
